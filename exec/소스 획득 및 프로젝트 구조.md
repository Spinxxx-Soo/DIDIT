## 2.2 Clone 및 초기 설정

### 1) 저장소 Clone

1. 저장소 클론
    

```bash
git clone https://lab.ssafy.com/s14-webmobile1-sub1/S14P11B202.git
```

2. 프로젝트 디렉터리로 이동
    

```bash
cd S14P11B202
```

### 2) 환경 변수(.env) 준비

- **백엔드 환경 변수**
    
    - `apps/server/.env`
        
    - 필요 시 `.env.example`을 참고하여 `.env` 생성 후 값 입력/수정
        
- **프론트엔드 환경 변수**
    
    - `apps/client/.env`
        
- **AI 서비스 환경 변수(선택)**
    
    - `apps/ai/.env` 로딩을 지원하며, 필요 시 생성하여 사용
        

### 3) 실행 방식 선택

- **로컬 개발용 실행:** `apps/server/docker-compose.yml`
    
- **배포/운영용 실행:** `infra/docker-compose/docker-compose.yml`

## 2.3 프로젝트 구조(모듈/디렉터리) 및 설정 파일 위치 규칙

### 1) 디렉터리 구조 요약

|경로|설명|
|---|---|
|`.gitlab/ci`|GitLab CI 파이프라인 구성(분리된 CI 설정)|
|`.vscode`|개발 환경 보조 설정|
|`apps/client`|프론트엔드 애플리케이션|
|`apps/server`|백엔드 API 서버|
|`apps/ai`|AI 서비스/워커|
|`infra/docker-compose`|배포/운영용 Docker Compose|
|`shared/api-spec`|공용 API 스펙|
|`exec`|실행 스크립트 또는 운영 보조 파일|
