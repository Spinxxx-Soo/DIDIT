#### 1단계: 로그인 및 프로젝트 초기 세팅 (Onboarding)

| **순서** | **화면(위치)** | **행동 (Action)** | **설명(Narration) 및 포인트** |
| --- | --- | --- | --- |
| **1** | **로그인 페이지** |   1\. ID 입력란에 `delay 202` 입력      2\. \[로그인\] 버튼 클릭   | "먼저 `delay 202` 계정으로 로그인을 진행합니다." |
| **2** | **메인 대시보드** |   1\. 마이페이지 하단 **\[+ 새 프로젝트 생성\]** 버튼 클릭      2\. 프로젝트 명에 `didit_front` 입력      3\. **\[생성\]** 버튼 클릭   | "새로운 프로젝트인 `didit_front`를 생성해보겠습니다." |
| **3** | **프로젝트 설정/홈** |   1\. GNB 좌측의 **\[GitHub 레포지토리 연동\]** 버튼 클릭      2\. 검색창 혹은 리스트에서 `pjtDidit/front` 선택      3\. **\[연동하기\]** 클릭   | "생성된 프로젝트에 GitHub 레포지토리를 연동합니다. 프론트엔드 레포지토리인 `pjtDidit/front`를 연결합니다." |
| **4** | **이슈(Kanban) 탭** |   1\. (연동 완료 직후) 이슈 탭으로 이동      2\. **(중요)** 잠시 1~2초 대기하여 빈 화면에서 이슈가 로딩되는 것 확인      3\. 데이터 로딩 후 이슈가 불러와진 것을 확인   | "보시는 것처럼 연동 즉시 GitHub의 이슈들이 자동으로 불러와집니다. 별도의 등록 과정 없이 이슈 관리를 시작할 수 있습니다." |
| **5** | **이슈 상세/리스트** |   1\. 연동해놓았던 깃헙 레퍼지토리 주소 클릭    2\. 새 탭으로 GitHub 페이지 열리는 것 확인, 기존 이슈들 확인 후 다시 복귀  | "필요하다면 아이콘을 클릭해 실제 GitHub 레포지토리로 바로 이동할 수도 있습니다." |
| **6** | **이슈 대시보드** |   1\. **\[이슈 현황/통계\]** 탭 클릭      2\. 그래프/차트가 생성된 것 확인   | "이슈들의 진행 상황도 시각화된 대시보드로 한눈에 확인할 수 있습니다." |
